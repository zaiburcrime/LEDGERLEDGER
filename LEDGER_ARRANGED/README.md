# Ledger - Student Financial Tracker

## How to open in VS Code
1. Extract this folder
2. In VS Code: File → Open Folder → select this folder (the one with `src` and `.vscode`)
3. Wait for the Java extension to load
4. Open `src/FinancialTracker.java`
5. Click the Run button above `main`, or press F5

## Or compile from terminal
```bash
cd src
javac -encoding UTF-8 *.java
java FinancialTracker
```
